# 机器人5网页答案展示规范 v2

来源为本地完整答案原文。原始格式列、数据库、JSON、Excel和人工评测字段不因展示转换改变。正文不调用模型改写，不添加转换说明、摘要、额外问候或结论。

| 项目 | 统一规则 |
| --- | --- |
| 输出容器 | HTML片段，带 `data-format-version="2"`，字号14px、行高1.7、正文色 #222；不输出整页 html/head/body/style |
| 标题与重点 | 按原文 Markdown 的层级和加粗语义展示；不自行增加或删除标题 |
| 段落与列表 | 保留原有段落、换行、有序及无序列表 |
| 表格 | 统一满宽、折叠边框、单元格内边距；表头浅灰底、加粗；保留全部单元格文字与数字 |
| 引用 | 合法 WeKnora 引用标签显示为 `[1]` 等编号，同一资料复用编号，文末按首次出现顺序列出资料名称。文档/片段ID继续完整保存在原文和技术明细中 |
| 代码及未知标签 | 原文真实代码块保留，未知 HTML 按文字转义；引用标签出现在代码块内时也保留为示例文字 |
| 链接 | 保留常规网页/邮件链接；脚本等危险协议不可执行 |
| 旧结果 | 从原始答案重新生成，不把旧网页正文或模型生成的转换前缀再当成原始答案；本次修复的5条旧异常结果有原始快照及精确内容保护 |
| 人工修改 | 后续发现已有未知或人工改动的网页内容时保留，并明确标为待复核；不能用该状态宣称统一排版验收成功 |
| 异常 | 空答案、格式检查失败或源文字缺失均逐条阻塞并保留错误码；不写入“转换失败”占位正文，也不影响其他正常问答 |

验收分别检查：结构及格式、正文文字保留、接口写入后的HTML回读、原始答案和人工字段未改、真实页面展示、重复执行零写入。接口写入一致不能单独代表展示质量通过。

回答自身的自然开场语、原有标题和代码示例按原文保留。v2 不删除或改写模型回答内容；本次消除的是展示转换附加的包装及不宜直接展示的引用技术字段。
